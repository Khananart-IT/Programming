## บทที่ 3 ชนิดตัวแปร Integer, Float

Integer เป็นตัวแปรคณิตศาสตร์แบบจำนวนเต็มทั้งจำนวนเต็มบวก จำนวนเต็มลบ จำนวนเต็มศูนย์

Float เป็นเป็นตัวแปรคณิตศาสตร์แบบจำนวนทศนิยม เช่น 0.0, 1.256, -4.1278

โดยการประกาศตัวแปรสำหรับทั้งสองชนิดตัวแปรไม่ต้องใส่เครื่องหมายอัญประกาศคู่ ("") หรืออัญประกาศเดี่ยว ('') ทั้งสิ้น

### 1. ตัวอย่างการประกาศตัวแปร integer

    NUMBER1 = 45
    NUMBER2 = 0.0
    NUMBER3 = -1.45
    NUMBER4 = 1.267

### 2. การใช้เครื่องหมายทางคณิตศาสตร์กับ Integer, Float

การใช้เครื่องหมายทางคณิตศาสตร์จะเป็นการคำนวณเลขแบบทั่วไปตามเครื่องหมายที่เราใช้

ข้อแนะนำเพิ่มเติม: หากทำการใช้เครื่องหมายทางคณิตศาสตร์กับ float จะได้ผลลัพธ์เป็นตัวแปรประเภท float เสมอ

|เครื่องหมายทางคณิตศาสตร์|การใช้งาน|ตัวอย่างโค้ด|ผลลัพธ์|
| -------- | -------- | -------- | -------- |
|+|การบวกเลข|print(32 + 54.4)|86.4|
|-|การลบเลข|print(100 - 42)|58|
|*|การคูณเลข|print(15 * 48.2)|723|
|/|การหารเลข|print(45 / 15)|3.0 (จะได้เป็นรูปทศนิยมอย่างน้อย 1 ตำแหน่งเสมอ)|
|**|การยกกำลัง|print(4 ** 0.5)|2.0|
|//|การหารเอาเฉพาะจำนวนเต็ม|print(6 // 4)|1|
|%|การหารเอาเฉพาะเศษ|print(7 % 3)|1|

### 3. การใช้เครื่องหมายเปรียบเทียบของ Integer, Float

เป็นการเปรียบเทียบระหว่าง ค่า 2 ค่าโดยค่าที่กลับมานั้นจะมีเฉพาะแค่ True กับ False เท่านั้น!

|เครื่องหมายเปรียบเทียบ|การใช้งาน|ตัวอย่างโค้ด|ผลลัพธ์|
| -------- | -------- | -------- | -------- |
|==|เปรียบเทียบระหว่างค่า 2 ค่าว่าเท่ากันไหม|print(65 == 65.0)|True|
|!=|เปรียบเทียบระหว่างค่า 2 ค่าว่าไม่เท่ากันไหม|print(45 != 12)|True|
|>|เปรียบเทียบว่าค่าของตัวที่ 1 มากกว่า ตัวที่ 2 ไหม|print(46 > 78)|False|
|>=|เปรียบเทียบว่าค่าของตัวที่ 1 มากกว่าหรือเท่ากับ ตัวที่ 2 ไหม|print(123 >= 123)|True|
|<|เปรียบเทียบว่าค่าของตัวที่ 1 น้อยกว่า ตัวที่ 2 ไหม|print(45 < 78)|True|
|<=|เปรียบเทียบว่าค่าของตัวที่ 1 น้อยกว่าหรือเท่ากับ ตัวที่ 2 ไหม|print(6 <= 4)|False|
