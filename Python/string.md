## บทที่ 2 ชนิดตัวแปร String

String เป็นตัวแปรประเภทข้อความ โดยการประกาศตัวแปรประเภทนี้ข้อความจะต้องอยู่ข้างใน **เครื่องหมายอัญประกาศคู่ ("")** 
หรือ **เครื่องหมายอัญประกาศเดี่ยว ('')** เสมอ

### 1. ตัวอย่างการประกาศตัวแปร

    x = "KFC"
    y = 'LOL'
    z = '10' #<--- 10 อันนี้จะถือเป็นตัวแปรชนิด String!

### 2. การใช้เครื่องหมายทางคณิตศาสตร์กับตัวแปร String

โดยการใช้เครื่องหมาย + หรือ * จะเป็นการต่อข้อความเข้าไป

ตัวอย่างการใช้

    x = "A"
    y = "B"
    print(x + y) #Output: AB
    print(x * 2) #Output: AA

**$\color{red}{\text{(ข้อควรระวัง!)}}$** 

1.การ + ต่อข้อความเข้าไปต้องเป็นประเภท String กับ String ด้วยกันเท่านั้น!

2.ถ้าเป็น * จะต้องเป็นตัว String คูณกับตัวแปรประเภท int (จำนวนเต็ม)!

### 3. ตำแหน่งของแต่ละตัวในตัวแปร String

เราสามารถเข้าถึงตัวอักษรแต่ละตัวใน String ได้ โดยใช้ **Index** ซึ่ง Index จะเริ่มที่ 0 เสมอ (เริ่มจากซ้ายไปขวา) หรือ -1 (เริ่มจากขวาไปซ้าย)

อธิบายเพิ่ม:

    x = "Apple"

จากในตัวแปร x จะสามารถเรียงลำดับ index ได้ดังนี้

|ตัวอักษร|ลำดับ (จากซ้ายไปขวา)|ลำดับ (จากขวาไปซ้าย)|
| -------- | -------- | -------- |
|A|0|-5|
|p|1|-4|
|p|2|-3|
|l|3|-2|
|e|4|-1|

ตัวอย่างการ print() ตัวอักษรในแต่ละ index ใช้ [(Index ที่ต้องการปริ้นออกมา)] ต่อท้ายตัวแปร

    x = "Apple"
    print(x[0]) #Output: A
    print(x[1]) #Output: p
    print(x[4]) #Output: e
    print(x[-2]) #Output: l
    print(x[5]) #จะเกิด IndexError เนื่องจากไม่มีตัวอักษรใน Index นั้น

### 4. การ String Slicing

เป็นการตัด String ออกเป็นส่วนย่อยๆโดยรูปแบบการ String Slicing จะเป็นดังนี้

**ชื่อตัวแปร[start:stop:step]** (step ไม่จำเป็นต้องใส่ก็ได้)

start คือ ตำแหน่งเริ่มต้นที่ต้องการให้แสดงผล (ค่า Default จะเป็น 0 หากไม่ใสค่า)

stop คือ ขอบเขตตำแหน่งสุดท้ายที่ต้องการ (ตัวที่อยู่ตำแหน่ง Stop จะไม่ถูกนำเข้ามารวมด้วย) (ค่า Default จะเป็น ความยาวของ String หากไม่ใส่ค่า)

step คือ เป็นการบอกว่าให้ก้าวไปครั้งละกี่ตัวอักษร เช่น 2 คือก้าวไปครั้งละ 2 ตำแหน่ง (ค่า Default จะเป็น 1 หากไม่ใสค่า)

ตัวอย่างการ String Slicing

    y = "Orange"
    print(y[1:5]) #Output: rang
    print(y[:2]) #Output: Or
    print(y[3:]) #Output: nge
    print(y[::-1]) #Output: egnarO (จะเป็นการพิมพ์ถอยหลัง)
    print(y[:3:2]) #Output: Oa
    print(y[1:10]) #Output: range
    print(y[6:]) #Output: 

จะสังเกตได้ว่าต่อให้เราใส่ Index ที่ไม่มีใน String นั้นโปรแกรมก็จะสามารถทำงานได้โดยไม่ติด Error

### 5.ฟังก์ชันที่เกี่ยวข้องกับ String

กำหนดให้ z = "PoRk ChOp"
|Function|การใช้งาน|ตัวอย่างโค้ด|ผลลัพธ์|
| -------- | -------- | -------- | -------- |
|upper()|ทำให้ทุกตัวอักษรใน String เป็นตัวพิมพ์ใหญ่|z.upper()|PORK CHOP|
|lower()|ทำให้ทุกตัวอักษรใน String เป็นตัวพิมพ์เล็ก|z.lower()|pork chop|
|capitalize()|ทำให้ตัวอักษรเฉพาะ index แรกเป็นตัวพิมพ์ใหญ่|z.capitalize()|Pork chop|
|title()|ทำให้ตัวอักษรตัวแรกของแต่ละคำเป็นตัวพิมพ์ใหญ่|z.title()|Pork Chop|
