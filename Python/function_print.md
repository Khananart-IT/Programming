## บทที่ 1 Function print()

ถือเป็นคำสั่งแรกที่นักเขียนโปรแกรมทุกคนต้องรู้จักคือคำสั่งสำหรับ **แสดงผลออกทางหน้าจอ**

ที่สำคัญ! ต้องเป็นตัวพิมพ์เล็กทั้งหมด เพราะ Python เป็นภาษาที่ Sensitive กับตัวพิมพ์เล็ก-ใหญ่ (Print หรือ PRINT จะสั่งงานไม่ได้ เกิด Error ทันที!)

### 1. การใช้งานพื้นฐาน (Basic Usage)
ใช้แสดงผลข้อมูลออกทางหน้าจอ ไม่ว่าจะข้อความ ตัวเลข หรือตัวแปร

    name = "John"
    print("Hello, World!")  # Output: Hello, World!
    print(100)              # Output: 100
    print(name)             # Output: John

### 2. sep = "" (Separator) — ตัวคั่นระหว่างวัตถุ
ปกติเวลาเราใส่ข้อมูลหลายๆ ตัวใน print() มันจะคั่นด้วยช่องว่าง (' ') ให้โดยอัตโนมัติ

แต่เราสามารถเปลี่ยนมันได้โดยการกำหนดตัวคั่นระหว่างข้อมูลแต่ละตัว

ตัวอย่างการใช้งาน:

    print("A", "B", "C", sep="-") #Output: A-B-C

เหมาะสำหรับสอนเรื่องการจัดฟอร์แมตข้อมูลเบื้องต้น โดยไม่ต้องต่อ String เองให้ยุ่งยาก

### 3. end = ""
ถ้าหากไม่ใส่ end มันจะขึ้นบรรทัดใหม่ทุกครั้งที่เรียกใช้ print() โดย end จะกำหนดสิ่งที่จะปิดท้ายบรรทัด **โดยไม่ขึ้นบรรทัดใหม่**

ตัวอย่างการใช้งาน:

    print("Hello", end="! ")
    print("World")
    #Output: Hello! World

### 4. การใช้ String Formatting (F-string)
ใช้สำหรับเวลาที่ต้องการพิมพ์ข้อความผสมกับตัวแปร

ตัวอย่างการใช้งาน:

    name = "Bank"
    age = 20
    print(f"Hello {name}! Age {age} year old.")
    # Output: Hello Bank! Age 20 year old.

### 5. การใช้ F-string ในการ Formatting Numbers
เวลาสั่งพิมพ์ตัวเลข เราสามารถกำหนดจำนวนทศนิยมหรือใส่ *เครื่องหมายจุลภาค (Comma)* ได้ทันทีใน print() ไม่ต้องเขียนโค้ดคำนวณให้ยุ่งยาก

ตัวอย่างการใช้:

    price = 1250000.789
    # กำหนดทศนิยม 2 ตำแหน่ง (ปัดเศษให้อัตโนมัติด้วยนะ!)
    print(f"ราคา: {price:.2f}")  # Output: ราคา: 1250000.79

    # ใส่เครื่องหมาย Comma คั่นหลักพัน
    print(f"ราคา: {price:,}")    # Output: ราคา: 1,250,000.789

    # รวมร่าง! ใส่ทั้ง Comma และทศนิยม 2 ตำแหน่ง
    print(f"ราคา: {price:,.2f}") # Output: ราคา: 1,250,000.79

โดย **{price:.Nf} จะเป็นการกำหนดทศนิยม N ตำแหน่ง**และ **{price:,} จะเป็นการใส่เครื่องหมาย Comma คั่นหลักพัน**

### 6. เทคนิค f-string Debugging (ใส่ = เพื่อดูชื่อตัวแปร)
**ใช้ได้ตั้งแต่ Python 3.8 ขึ้นไป** เวลาเขียนโปรแกรมแล้วอยากเช็กค่าตัวแปร ไม่ต้องมานั่งพิมพ์ชื่อตัวแปรรอบสองให้เสียเวลา!

ตัวอย่างการใช้:

    x = 10
    y = 20

    # แบบเดิมที่ชอบพิมพ์กัน (ถึกและเสียเวลา)
    print(f"x = {x}, y = {y}")

    # แบบเซียน! ใส่ = ต่อท้ายชื่อตัวแปรได้เลย
    print(f"{x=}, {y=}")       # Output: x=10, y=20
    print(f"{x + y=}")         # Output: x + y=30 (สามารถคำนวณได้ด้วย)

### 7. การจัดตำแหน่งข้อความ (Alignment & Padding)
หากอยากจะจัดข้อความให้อยู่ ชิดซ้าย, ชิดขวา, หรือ ตรงกลาง พร้อมเติมตัวอักษรใส่ช่องว่างก็ทำได้!

ตัวอย่างการใช้:

    text = "PYTHON"

    print(f"{text:>10}")   # ชิดขวา ในพื้นที่ 10 ช่อง   -> '    PYTHON'
    print(f"{text:<10}")   # ชิดซ้าย ในพื้นที่ 10 ช่อง   -> 'PYTHON    '
    print(f"{text:^10}")   # ตรงกลาง ในพื้นที่ 10 ช่อง  -> '  PYTHON  '

    # เติมตัวอักษรแทนที่ช่องว่าง (เช่น ใส่ * ล้อมรอบ)
    print(f"{text:*^12}")  # Output: ***PYTHON***
    #ถ้าไม่ใส่อะไรเลยหลัง ":" จะเป็นช่องว่าง

### 8. Escape Character (รหัสควบคุมการแสดงผล)
บางทีเราอยากเว้นวรรคยาวๆหรือขึ้นบรรทัดใหม่ภายในข้อความเดียวโดยไม่ต้องใช้ print() หลายบรรทัดให้ใช้สัญลักษณ์พวกนี้

|Escape Character|ความหมาย|ตัวอย่างโค้ด|Output|
| -------- | -------- | -------- | -------- |
|**\n**|ขึ้นบรรทัดใหม่ (New Line)|print("Line1\nLine2")|Line1<br>Line2|
|**\t**|เว้นช่องว่างแบบ Tab|print("Name:\tJeff")|Name: Jeff|
|**\\" , \\'**|พิมพ์เครื่องหมายอัญประกาศ|print("He said \"Hi\"")|He said "Hi"|
|**\\\\**|พิมพ์เครื่องหมาย Backslash|print("C:\\\\Users\\\\Jeff")|C:\Users\Jeff|
