# เรียน C# EP1 โครงสร้างของ C#, คำสั่งพิมพ์ออกจอ, การเขียนคอมเมนต์, ตัวแปร, การรับค่าจากผู้ใช้
## บทที่ 1 โครงสร้างบ้านของ C#
### ตัวอย่างโค้ดของ C#

$\color{orange}{\text{
    using System;
    class Program
    {
        static void Main() 
        {
            Console.WriteLine("Hello, Game Developer!");
        }
    }
}}$

## ถอดรหัสส่วนประกอบ:

-using System; --> คือการดึงกล่องอุปกรณ์มาตรฐานของ C# มาใช้ (ถ้าไม่มีคำสั่งนี้ มันจะไม่รู้จักคำว่า Console)

-class Program { ... } --> คือตัวบ้านหลัก สำหรับเก็บโค้ดของเรา

-static void Main() { ... } --> คือ ประตูทางเข้าบ้าน (Main Method) 
คอมพิวเตอร์จะวิ่งมาเริ่มทำงานตรงบรรทัดแรกที่อยู่ในปีกกา { } ของ Main เสมอ

-; (Semicolon) --> **$\color{red}{\text{สำคัญที่สุด!}}$** เปรียบเหมือนจุด . (Full stop) ปิดท้ายประโยค ทุกบรรทัดคำสั่งใน C# ต้องปิดด้วย ; เสมอ (ยกเว้นบรรทัดที่มีปีกกา { })

## บทที่ 2 คำสั่งพิมพ์ออกหน้าจอ (Console)
-เป็นคู่หูหลักที่เราจะใช้ในการแสดงผล มี 2 คำสั่งนี้:

1.Console.WriteLine("ข้อความ");

-เมื่อพิมพ์ข้อความเสร็จแล้ว "ปัดขึ้นบรรทัดใหม่" ให้ทันที (เหมือน print() ใน Python)

2.Console.Write("ข้อความ");

เมื่อพิมพ์ข้อความเสร็จแล้ว "แช่เคอร์เซอร์ไว้ที่เดิม" ไม่ขึ้นบรรทัดใหม่ (เหมือน print(..., end="") ใน Python)

### ตัวอย่างการทำงาน:

$\color{yellow}{\text{
    Console.Write("Welcome ");
    Console.Write("to ");
    Console.WriteLine("My Arcade Game!");
    Console.WriteLine("Let's start!");
}}$

ผลลัพธ์ที่ได้ทางหน้าจอ:

$\color{yellow}{\text{
    Welcome to My Arcade Game!
    Let's start!
}}$

## บทที่ 3 การเขียนคอมเมนต์ (Comment)

-เอาไว้เขียนโน้ตเตือนความจำตัวเอง คอมพิวเตอร์จะข้ามบรรทัดนี้ไป ไม่นำมารันเป็นโค้ด:

แบบที่ 1 // (Double Slash): คอมเมนต์บรรทัดเดียว

$\color{green}{\text{
    // บรรทัดนี้คือการแสดงผลชื่อเกม
    Console.WriteLine("Arcade Tycoon");
}}$

แบบที่ 2 /* ... */: คอมเมนต์แบบหลายบรรทัด

$\color{green}{\text{
    /*

        โค้ดส่วนนี้เขียนโดย

        โปรแกรมเมอร์สุดเท่

    */
}}$

## บทที่ 4 ตัวแปร
### 1.int (Integer - จำนวนเต็ม)

-ใช้เก็บตัวเลขเต็มๆ ไม่มีจุดทศนิยม เหมาะสำหรับนับจำนวนที่ไม่มีครึ่งๆ กลางๆ

ตัวอย่างการใช้งาน: จำนวนชีวิต, เลเวลตัวละคร, สกอร์คะแนน, กระสุนที่เหลือ

### ตัวอย่าง

$\color{cyan}{\text{
    int playerHealth = 100;
    int currentLevel = 1;
    int ammo = 30;
}}$

### 2.float (Floating Point - ตัวเลขทศนิยม)

-ใช้เก็บตัวเลขที่มีจุดทศนิยม เหมาะสำหรับการคำนวณที่ต้องการความละเอียด เช่น ระยะเวลา หรือ ความเร็ว

### ข้อสังเกตสำคัญ: ตัวเลขทศนิยมใน C# จะต้องมีอักษร f ต่อท้ายเสมอ เพื่อบอกโปรแกรมว่าเป็นชนิด float

ตัวอย่างการใช้งาน: ความเร็วการเดิน, เวลาถอยหลัง, ค่าความแรงในการโดดC#float moveSpeed = 5.5f;

### ตัวอย่าง

$\color{cyan}{\text{
    float jumpForce = 12.0f;
    float timer = 60.0f;
}}$

### 3.bool (Boolean - ตรรกะ จริง/เท็จ)เก็บค่าได้เพียงแค่ 2 สถานะ เท่านั้น คือ true (จริง) หรือ false (เท็จ)

-เหมาะสำหรับใช้เป็นสวิตช์เปิด-ปิดเงื่อนไขในเกม

ตัวอย่างการใช้งาน: ตัวละครยืนอยู่บนพื้นไหม?, เกมจบหรือยัง?, กำลังหมอบอยู่หรือไม่?

### ตัวอย่าง

$\color{cyan}{\text{
    bool isGrounded = true;
    bool isGameOver = false;
    bool canDoubleJump = true;
}}$

### 4.string (String - ข้อความ)

-ใช้เก็บตัวอักษร คำ หรือประโยคยาวๆ **$\color{red}{\text{โดยข้อความจะต้อง อยู่ภายในเครื่องหมายอัญประกาศคู่ (" ") เสมอ}}$**

-ตัวอย่างการใช้งาน: ชื่อตัวละคร, ข้อความบทสนทนา (NPC), ชื่อไอเทม

### ตัวอย่าง

$\color{cyan}{\text{
    string playerName = "Hero123";
    string dialogueText = "สวัสดี ยินดีต้อนรับสู่หมู่บ้าน!";
}}$

### 5.char (Character - ข้อมูลตัวเดียว)

-เป็นการเก็บข้อมูลของอักขระเพียงตัวเดียวไว้ใช้สำหรับ Rank (S, A, B) **$\color{red}{\text{โดยอักขระตัวนั้นจะต้อง อยู่ภายในเครื่องหมายอัญประกาศเดี่ยว (' ') เสมอ}}$**

### ตัวอย่าง

$\color{cyan}{\text{
    char rank = 'A';
}}$

### เสริม.Vector2 และ Vector3 (เวกเตอร์ - พิกัด/ทิศทาง)

-ประเภทข้อมูลพิเศษของ Unity ใช้เก็บ ชุดตัวเลขทศนิยมเป็นกลุ่ม เพื่อบอก ตำแหน่ง หรือ ทิศทาง

Vector2: เก็บค่า (X, Y) เหมาะสำหรับเกม 2D (ซ้าย-ขวา, บน-ล่าง)

Vector3: เก็บค่า (X, Y, Z) เหมาะสำหรับเกม 3D (บวกแกน ลึก-ตื้น เข้ามา)

-ตัวอย่างการใช้งาน: ทิศทางการเดิน, พิกัดเกิดของศัตรู

### ตัวอย่าง

$\color{cyan}{\text{
// ทิศทาง 2D: ไปทางขวา (X=1) และไม่อยู่บน-ล่าง (Y=0)
Vector2 moveDirection = new Vector2(1.0f, 0.0f);

// พิกัด 3D: ตำแหน่งเกิดในฉาก (X=0, Y=5, Z=10)
Vector3 spawnPosition = new Vector3(0f, 5f, 10f);
}}$

## บทที่ 5: การรับค่าจากผู้ใช้ (Console Input)

### คำสั่งรับค่า: Console.ReadLine()

ใน Python เราใช้ input() แต่ใน C# เราจะใช้คำสั่ง Console.ReadLine();

เมื่อโค้ดวิ่งมาถึงบรรทัดนี้ โปรแกรมจะหยุดรอให้ผู้ใช้พิมพ์ข้อความลงใน Console แล้วกด Enter

### ตัวอย่างการรับชื่อผู้เล่น:

$\color{blue}{\text{
    Console.Write("Enter player name: ");
    string playerName = Console.ReadLine(); // รับข้อความมาเก็บไว้ในตัวแปร playerName

    Console.WriteLine("Hello, " + playerName + "!");
}}$

**$\color{red}{\text{จุดสำคัญ: Console.ReadLine() จะส่งค่ากลับมาเป็น string เสมอ!}}$**

ไม่ว่าผู้ใช้จะพิมพ์เลข 10 หรือข้อความ "Alex" สิ่งที่ Console.ReadLine() อ่านได้จะเป็นข้อความ (string) เสมอ

ดังนั้นถ้าเราจะรับข้อมูลตัวเลขเอาไปคำนวณ เช่น อายุ, เลเวล, หรือจำนวนเหรียญ

เราจะสามารถทำได้ด้วยวิธีการนี้:

### วิธีแปลงข้อความให้เป็นตัวเลข (Type Casting / Parsing)
แปลงเป็น int (จำนวนเต็ม):

$\color{blue}{\text{
    int age = int.Parse(Console.ReadLine());

แปลงเป็น float (ทศนิยม):

    float speed = float.Parse(Console.ReadLine());
}}$

**$\color{red}{\text{ใช้ (ชนิดตัวแปร).Parse() กับตัวแปรประเภท int และ float เสมอ}}$**
